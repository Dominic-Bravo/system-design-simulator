# MVP Roadmap (from `readme.md`)

## Phase 1 — Foundation
**Goal:** Build the interactive graph experience first (learning through visualization).

### Features
- Drag-and-drop nodes
- Create connections
- Save/load systems
- Basic animations
- Simple request flow

### Supported nodes (MVP)
- API
- Database
- Cache
- Queue
- Load balancer

---

## Phase 2 — Basic Simulation
**Goal:** Turn the graph into a simulator with measurable outcomes.

### Features
- Latency simulation
- Traffic volume
- Failure simulation
- Retry behavior
- Queue buildup
- Bottleneck detection

---

## Phase 3 — Learning Features
**Goal:** Add mentoring, scoring, and guided practice.

### Features
- Guided tutorials
- Architecture scoring
- System challenges
- AI explanations
- Recommendations

---

## Phase 4 — Advanced Simulation
**Goal:** Expand simulation realism and system-design depth.

### Features
- Kubernetes concepts
- Regional traffic
- Distributed systems
- Cloud cost estimation
- Replication simulation
- Autoscaling

---

## Phase 5 — Collaboration
**Goal:** Enable teamwork and iteration on architectures.

### Features
- Team collaboration
- Shared projects
- Architecture reviews
- Comments
- Version history
- Branching
