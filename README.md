# System Design Simulator

This repository contains a React + TypeScript frontend for building a system architecture graph and running a basic latency simulation.

## Project Structure

```text
frontend/   React, TypeScript, Vite application
```

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

On Windows PowerShell, use `npm.cmd` if script execution policy blocks `npm`:

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

Then open the Vite URL printed in the terminal, usually `http://localhost:5173`.

## Run Checks

```bash
cd frontend
npm run lint
npm run build
```

See `frontend/README.md` for full usage instructions.
